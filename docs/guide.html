1압축 풀기

받은 FINDEROAD.zip 을 더블클릭해서 풀어요.

2응용 프로그램 폴더로

FINDEROAD.app 을 Finder 왼쪽의 응용 프로그램 폴더로 끌어다 놓아요. 그래야 자동 업데이트가 돼요.

3처음 열 때 경고가 뜨면

시스템 설정 → 개인정보 보호 및 보안 맨 아래에서 "그래도 열기" 를 눌러요. 다음부터는 바로 열려요.

이름 · 확장자

큰 검색 칸에 파일 이름 일부를 쓰면 바로 찾아요. 띄어 쓰면 모든 낱말이 들어간 파일만 나와요.
확장자 칸에 hwp hwpx 처럼 여러 개를 넣으면 함께 찾아요(쉼표 · 띄어쓰기로 나눠요). 고르기 ▾ 를 누르면 종류별로 체크해서 골라요.

무엇을 찾을까요? (분류)

누르면 그 분류의 확장자가 더해지고, 다시 누르면 빠져요. 여러 개를 함께 켤 수 있어요. 전체 는 확장자 조건을 비워요. 직접 고르기 는 확장자 고르기 창을 열어요.

어디서 찾을까요? (검색 범위)

Mac 전체: Spotlight 로 먼저 빠르게 보여 주고, 그동안 폴더를 끝까지 직접 살펴 빠진 파일을 채워요. 찾는 동안 진행 막대가 보이고 그만 찾기(Esc) 로 멈춰요.
선택한 폴더: 폴더를 추가하거나 Finder 에서 창으로 끌어다 놓으면 여러 폴더를 함께 찾아요. 결과 화면에서는 검색 칸 오른쪽 범위 ▾ 에서 바꿔요.

카드 · 목록 · 정렬

결과는 카드(그림으로 크게) 또는 목록(표)으로 볼 수 있고, 고른 보기는 기억해요.
이름으로 찾으면 정확도순: 이름이 똑같은 파일(이름 일치 표시)부터 보여 줘요. 목록에서는 표 머리, 카드에서는 정렬 ▾ 로 이름 · 위치 · 크기 · 수정일 순서를 바꿔요.

끌어서 옮기기 · 보낼 곳

결과를 끌어서 Finder 창 · 데스크탑에 놓으면 옮겨져요(다른 디스크로는 복사, ⌥ 는 복사).

숨김 파일이나 라이브러리 폴더까지 찾으려면 검색 범위의 숨김 · 시스템 파일도 찾기 를 켜요.

4꼭 알아 두세요

  • 즉시 삭제는 되돌릴 수 없어요. 휴지통에도 남지 않아요. 확인 창의 파일 목록을 꼭 확인하세요. 평소에는 휴지통으로(⌘⌫)를 쓰세요.
  • 되돌리기는 바로 앞의 작업 하나만 돼요. 앱을 다시 열면 되돌릴 수 없어요. Finder 에 끌어다 놓은 것은 Finder 에서 ⌘Z 로 되돌려요.
  • 같은 이름이 있으면 덮어쓰지 않아요. '파일 2.mp4' 처럼 번호를 붙여 둘 다 남겨요.
  • Mac 전체 검색은 홈 폴더 · iCloud Drive · 외장 디스크까지 직접 살펴요. 파일이 아주 많으면 시간이 걸려요(최대 2분). 네트워크 디스크는 '선택한 폴더' 에 추가해서 찾아요.
  • 데스크탑 · 문서 · 다운로드 폴더 를 처음 찾을 때 접근을 허용할지 물어요. 허용 을 눌러 주세요. 업데이트 뒤에 다시 물을 수도 있어요.
  • 시스템 폴더와 맥의 기본 폴더(문서 · 데스크탑 등) 자체는 실수로 옮기거나 지우지 않도록 막아 두었어요. 그 안의 파일은 괜찮아요.
  • 창을 닫아도 앱은 Dock 에 남아요. 완전히 끄려면 ⌘Q. 함께 돌던 엔진도 같이 꺼져요.
  • 자동 업데이트 는 앱을 응용 프로그램 폴더에서 열었을 때만 돼요. 오른쪽 위 업데이트 확인 에서 버전 확인 · 직접 업데이트 · 자동 업데이트 켜고 끄기를 해요.
